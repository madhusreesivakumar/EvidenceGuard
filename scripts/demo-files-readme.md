This directory and guide explain how to conduct a live demonstration of EvidenceGuard's cryptographic evidence verification and tamper detection.

All demo files are automatically generated by `node scripts/seed.js --confirm` and reside in `./demo-files/` (gitignored).

## 2. Live Demo Script for Presentations & Evaluators

### Step A: Verify Original File (Green / VERIFIED)
1. Log in as `demo.investigator@evidenceguard.local` (or `demo.admin@evidenceguard.local`).
2. Navigate to **Verify Evidence** (`verify.html`).
3. In **Step 1: Identify Evidence**, enter `EV-0002` (or Case ID). Click **Lookup**.
4. In **Step 2: Upload File for Verification**, drag and drop or browse to `./demo-files/crime_scene.png`.
5. In **Step 3: Verification Result**, click **Verify Evidence**.
6. **Result**: Shows bright green **VERIFIED** badge, matching SHA-256 hashes, and confirmed ledger consistency.

### Step B: The Live Tamper Moment (Red / TAMPERED)
1. Stay on **Verify Evidence** (`verify.html`).
2. Lookup `EV-0002` (Crime Scene Image).
3. Now upload the modified copy: `./demo-files/crime_scene_tampered.png`.
4. Click **Verify Evidence**.
5. **Result**: The system immediately detects the single-byte cryptographic disparity!
   - Bright red **TAMPERED** banner.
   - Shows Registered Hash vs Submitted Hash side-by-side.
   - A `TAMPER_DETECTED` security audit event is instantly logged in the append-only audit trail (`audit.html`).

### Step C: Inspecting Pre-existing Tamper Record (EV-0004)
1. Go to **Evidence Records** (`records.html`).
2. Filter or locate `EV-0004` (`Audio Recording`).
3. Notice the red `Tampered` status badge and the `DEMO` badge.
4. Click **View Details** (`evidence-details.html?id=EV-0004`).
5. Scroll down to the **Verification History** table:
   - Observe the historical verification row with status `TAMPERED`.
   - Click **View Audit Trail** to see the chronological chain of custody events (`HASH_GENERATED`, `UPLOAD`, `BLOCK_CREATED`, `VERIFY`, `TAMPER_DETECTED`).

### Step D: Blockchain Ledger Verification
1. Log in as `demo.admin@evidenceguard.local`.
2. Navigate to **Blockchain Ledger** (`blockchain.html`).
3. Click **Validate Entire Chain**.
4. The system cryptographically traverses every block from Genesis (Block #0) to the latest block, verifying `previousHash` links and SHA-256 block hashes in milliseconds.
5. All 5 demo records are anchored into the immutable ledger!
