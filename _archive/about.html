About EvidenceGuard

Evidence Protection System Using Blockchain Technology — College Project

🎓 Frontend Demo | Academic Project 2026
⚠️ The Problem
Digital evidence — including CCTV footage, images, audio recordings, and documents — can be easily copied, modified, or deleted without leaving any visible trace. Traditional storage methods provide no reliable mechanism to confirm whether the evidence presented in court or investigation is the original, unaltered file.

This undermines the integrity, authenticity, and admissibility of digital evidence in legal and security contexts.
✅ Our Solution
EvidenceGuard generates a SHA-256 digital fingerprint for each evidence file when it is first uploaded. This unique hash is then stored as part of a hash-linked chain of records, inspired by blockchain architecture.

At any point, the file can be re-submitted for verification. If its hash matches the stored hash, the evidence is VERIFIED as original. Any mismatch immediately signals TAMPERING.

Project Workflow

Step-by-step process from evidence upload to verification.

1. Upload Evidence

Officer uploads a digital file (image, video, audio, document) via the platform.

2. Generate SHA-256 Hash

The Web Crypto API computes a unique 256-bit cryptographic hash of the file content.

3. Register Evidence

The evidence metadata and hash are saved as a secure, timestamped record.

4. Blockchain Hash Linking

A new block is created, containing the evidence hash and the previous block's hash, forming the chain.

5. Verify Evidence

Re-upload the file at any time. The system recomputes and compares the hash.

6. Verified ✅ or Tampered ❌

If hashes match → VERIFIED. If hashes differ → evidence has been tampered with.
