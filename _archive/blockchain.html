🧪 Local Hash-Chain Demo
⛓ What is this?

Each evidence record is added as a block in the chain. Every block contains the SHA-256 hash of the previous block, linking them together.


🔒 If any earlier block is modified, its hash changes — breaking the link to all subsequent blocks. This makes tampering immediately detectable.


⚠️ This is a local, browser-based hash-chain demonstration using the Web Crypto API. In a production system, this would be written to a distributed ledger.

🔎 Chain Info
Genesis Block — The first block, with a fixed previous hash of zeros. Acts as the chain anchor.
Evidence Blocks — Each subsequent block stores the evidence ID, its SHA-256 hash, and the previous block's hash.
Hash Linking — Each block's "Previous Hash" equals the "Current Hash" of the block above it.
