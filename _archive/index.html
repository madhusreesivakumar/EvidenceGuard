About the Project

Why EvidenceGuard? The problem and our solution.

⚠️ The Problem
Digital evidence can be easily copied, modified, or deleted. Traditional storage methods provide no reliable way to confirm whether the evidence presented is original or has been altered since collection.
✅ Our Solution
EvidenceGuard generates a SHA-256 digital fingerprint for each evidence file and uses hash-linked records (blockchain concept) to support integrity verification — ensuring any tampering is immediately detectable.

How It Works

Simple, transparent, and verifiable in seconds.

1

Upload Evidence

2

Generate Hash

3

Register Record

The evidence metadata and hash are saved as a secure record.

4

Blockchain Linking

Each record links to the previous block using the hash chain.

5

Verify Anytime

Re-upload the file later to confirm it is unchanged and verified.
